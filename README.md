# Siyu Wang — academic website

Personal academic website of Siyu Wang, Postdoctoral Fellow at UNSW Sydney.

Website: https://sy-siyu.github.io/

## Publishing

This is a buildless static website. In GitHub Settings → Pages, choose
“Deploy from a branch”, then `main` and `/ (root)`.

The homepage is `index.html`; the publications archive is
`publications/index.html`. Styles, scripts, images and fonts are in `assets/`.
The `.nojekyll` file disables Jekyll processing.

This repository starts with the redesigned website, without the previous
template’s Git history. Third-party notices and font licences are retained;
see `THIRD_PARTY_NOTICES.md`.
